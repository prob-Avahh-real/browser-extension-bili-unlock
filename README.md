# 浏览器插件：B 站专用视频增强

这是一个针对 B 站播放器的增强型浏览器扩展，目标是让你在 B 站视频页上更方便地使用常见播放控制能力：

- 倍速控制：0.75x / 1x / 1.25x / 1.5x / 2x / 2.5x
- 清晰度控制：4K / 1080p / 720p / 480p / 360p / 自动
- 进度控制：快退 30 秒 / 快进 30 秒
- 连播控制：尝试点击播放器中的连播/自动相关按钮

## 安装方法

1. 打开 Chrome / Edge 扩展页：chrome://extensions
2. 打开“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择当前目录：/Users/skat/projects/browser-extension-bili-unlock
5. 访问任意包含视频的网页后，点击扩展图标即可启用

## 注意

- 由于不同网站的播放器实现差异很大，某些站点的清晰度切换按钮可能无法被准确识别。
- 该插件更适合作为“增强体验”的演示原型，而不是万能破解器。

  - 自动识别当前站点并生成不同策略
  - 增加“自动 2x 倍速 + 自动清晰度”一键模式
